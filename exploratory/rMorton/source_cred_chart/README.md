source_cred_chart
===============================

A Jupyter Widget Library for Source Cred's Force Directed Chart

Installation
------------

To install use pip:

    $ pip install source_cred_chart
    $ jupyter nbextension enable --py --sys-prefix source_cred_chart


For a development installation (requires npm),

    $ git clone https://github.com//source_cred_chart.git
    $ cd source_cred_chart
    $ pip install -e .
    $ jupyter nbextension install --py --symlink --sys-prefix source_cred_chart
    $ jupyter nbextension enable --py --sys-prefix source_cred_chart
